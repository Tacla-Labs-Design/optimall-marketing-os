# examples/ — acervo curado

Materiais prontos do Optimall, para ver como o padrão fica na prática: e-mail, deck e post.
É **leitura**, não destino de escrita — o trabalho de cada pessoa nasce em `saida/`.

Só o maintainer grava aqui. Quando um material ficar bom o bastante para virar referência,
mande para quem cuida do repositório.

Por enquanto, o acervo está vazio.

Exemplo publicado aqui segue a mesma regra do repositório público: sem tela do produto, sem
foto de banco de imagem, sem dado de cliente e sem briefing do time.
